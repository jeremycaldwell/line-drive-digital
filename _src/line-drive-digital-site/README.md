# Line Drive Digital website

Static HTML/CSS with a little vanilla JS. No build step: open `index.html` in a browser, or upload the folder to any static host (Netlify, Cloudflare Pages, GitHub Pages).

## Pages
- `index.html` (Home), `services.html`, `work.html`, `about.html`, `contact.html`

## Assets (`assets/`)
- `favicon.svg`, `favicon-animated.svg`, `stamp.svg`, `ld-mark.svg`, `ld-mark-animated.svg`
- `line-drive-digital*.svg`: the logo, static or animated, light or dark (type converted to outlines)

## Before launch
- Replace every `[PLACEHOLDER]` (prices, email, phone, hours, client names, results, photos).
- The contact form only shows a "sent" message; connect it to a form handler (e.g. Netlify Forms, Formspree).
- Fonts load from Google Fonts (Outfit, Inter, IBM Plex Mono, Adamina).
